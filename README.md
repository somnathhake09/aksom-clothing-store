# 🛍️ AKSom Cloths

A full-stack e-commerce clothing website with product browsing,
cart management, and user authentication.

## 🚀 Tech Stack
- **Frontend:** React, Vite, Bootstrap
- **Backend:** Node.js, Express
- **Database:** MySQL
- **Auth:** JWT

## ✨ Features
- Men, Women, Kids & Accessories categories
- Product listing & detail pages
- Add to cart / remove from cart
- User login & logout
- Responsive design

## 🛠️ Setup

### Frontend
cd frontend
npm install
npm run dev

### Backend
cd backend
npm install
npm start
